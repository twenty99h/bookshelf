# Приложение владеет рабочим состоянием изучения

Приложение является источником истины для расписания, идей, экспериментов и восстановления знаний, а готовые материалы односторонне экспортируются в Markdown для хранения и дальнейшего использования в Obsidian. Будущая интеграция с Google Calendar также будет односторонней: Bookshelf создаёт и обновляет события, но календарь не изменяет расписание приложения. Двусторонняя синхронизация отклонена, поскольку она размывает владельца данных и требует разрешать конфликты между изменениями во внешних инструментах и Bookshelf.
