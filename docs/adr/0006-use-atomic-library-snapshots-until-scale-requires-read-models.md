# Использовать атомарный снимок библиотеки до подтверждённой проблемы масштаба

Rust возвращает после изменяющих команд полный `LibraryState`, а page-local модуль Svelte атомарно заменяет текущий снимок без TanStack Query и протокола частичных патчей. Это сохраняет один источник истины и исключает ошибки инвалидизации в локальном однопользовательском приложении; нормализованные таблицы SQLite, отдельные read models и адресный кеш откладываются до измеренной проблемы с объёмом JSON, задержкой записи или IPC.
