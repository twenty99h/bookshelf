# Переносить локальную библиотеку цельным архивом

Первая Windows-версия desktop-приложения копирует импортированные PDF во внутреннюю локальную библиотеку вместе с рабочим состоянием изучения и поддерживает редкий перенос цельным экспортируемым архивом. Основной архив самодостаточен, включает PDF и всегда шифруется заданным пользователем паролем без возможности восстановления; приложение также автоматически хранит несколько последних облегчённых снимков состояния без книг. Локальная библиотека отдельно не шифруется и полагается на защиту диска операционной системой.

Постоянная синхронизация и Git как рабочее хранилище отклонены: они требуют разрешения конфликтов, плохо сочетаются с PDF и живой базой данных и существенно расширяют продукт; Git остаётся подходящим внешним инструментом для экспортированных Markdown-материалов.
