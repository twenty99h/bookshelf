# Интегрировать ИИ через локальный Codex App Server

Первая версия не использует OpenAI Platform API и не требует отдельной оплаты токенов: desktop-приложение обращается к локальному Codex App Server, который проводит официальный ChatGPT OAuth-вход и использует доступ к GPT-5.6 Luna в рамках личной подписки Pro 5x. Зависимость принимается как экспериментальная и потенциально изменчивая; ручная передача того же пакета проверки во внешний чат остаётся fallback.

PDF целиком и локальная библиотека не передаются Codex: он запускается из изолированной папки приложения и только по явному действию читателя получает формулировку идеи, выбранный фрагмент книги, конкретный вопрос и явные критерии ответа, а эксперименты и другие заметки не добавляются автоматически. Токены ChatGPT не копируются и не хранятся Bookshelf, после переноса на другой компьютер пользователь входит заново. ИИ остаётся необязательным критиком, поэтому чтение, фиксация идей, эксперименты и восстановление знаний работают без него.
