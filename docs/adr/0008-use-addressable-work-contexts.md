# Сделать рабочие контексты адресуемыми

Bookshelf использует SvelteKit routes для рабочего стола, библиотеки, книги, режима чтения, черновиков, знаний, идеи, практики и настроек; route-файлы остаются тонкими входами в FSD page slices. Это решение заменяет единый стек экранов на Svelte state: отдельные адреса позволяют восстановить книгу или идею после перезапуска, дают естественную историю переходов и делают Playwright-сценарии устойчивыми, при этом приложение сохраняет одно desktop-окно и не поддерживает параллельные рабочие контексты.
