# 08 — Плотная библиотека и страница книги

**What to build:** Позволить читателю быстро оценить состояние личной библиотеки, выбрать книгу и перейти в нужную часть её изучения через адресуемую страницу книги.

**Blocked by:** 02 — Визуальный фундамент и адресуемый shell.

**Status:** ready-for-agent

- [ ] Библиотека показывает 8–10 строк книг при Full HD с корешком или обложкой, названием, статусом, последней позицией, количеством черновиков и одним главным действием.
- [ ] Фильтры различают все, активные, приостановленные, готовые, завершённые и архивные книги; сортировки поддерживают последнее обращение, название и прогресс чтения.
- [ ] Выбор книги открывает адресуемую страницу со статусом, прогрессом чтения, действием «Продолжить чтение» и вкладками «Обзор», «Черновики», «Идеи», «Практика».
- [ ] Технические свойства PDF, архивирование и постоянное удаление находятся во вторичном меню и не конкурируют с продолжением чтения.
- [ ] Пустая библиотека ведёт к первому импорту, а пустой результат фильтра объясняет состояние и способ сброса.
- [ ] Baselines `library-list` и `book-overview` проходят при 1920×1080; функциональный сценарий остаётся рабочим при 1280×720.
- [ ] Page-level tests проверяют доступную навигацию и состояния через предметный command seam, не мокая низкоуровневый Tauri transport.
