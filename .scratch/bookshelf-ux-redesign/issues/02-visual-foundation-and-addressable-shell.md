# 02 — Визуальный фундамент и адресуемый shell

**What to build:** Дать самостоятельному читателю цельный тёмный desktop-shell с понятной навигацией и восстанавливаемыми рабочими контекстами, а при первом запуске — одно ясное действие импорта PDF.

**Blocked by:** 01 — Детерминированный Playwright-контур.

**Status:** ready-for-agent

- [ ] Основная навигация ведёт на рабочий стол, библиотеку, черновики, знания, практику и настройки и показывает текущий раздел Lucide-иконкой вместе с текстом.
- [ ] Рабочий стол, библиотека, книга, reader, черновики, знания, идея, практика и настройки имеют согласованные адресуемые SvelteKit-контексты с естественной историей переходов.
- [ ] Route entries остаются тонкими, экранная композиция начинается в page slices, а app-level shell не переносит предметную логику в shared.
- [ ] Night, Graphite, Slate, Mist, Iris и Amber применены с согласованными ролями; локальные IBM Plex Sans/Mono загружаются без сети.
- [ ] Tailwind оформляет прикладной UI, а Bits UI доступен экранам только через собственные shared-примитивы.
- [ ] Первый запуск объясняет локальность данных и показывает единственный основной CTA «Импортировать PDF» без onboarding-карусели.
- [ ] Baseline `first-run` проходит при 1920×1080, shell остаётся рабочим при 1280×720 и доступен с клавиатуры.
