# 03 — Непрерывный адресуемый режим чтения

**What to build:** Позволить самостоятельному читателю открыть книгу в отдельном защищённом режиме чтения, непрерывно прокручивать PDF и после перезагрузки продолжить с сохранённой позиции.

**Blocked by:** 02 — Визуальный фундамент и адресуемый shell.

**Status:** ready-for-agent

- [ ] Адрес книги открывает отдельный reader shell без основной навигации и сохраняет стандартное desktop-окно с системным fullscreen по F11.
- [ ] Постоянный toolbar показывает возврат, название и главу, позицию, масштаб, поиск, состояние сохранения и управление сайдбаром.
- [ ] PDF отображается непрерывной виртуализированной лентой; соседние страницы готовятся заранее, дальние освобождаются, placeholders сохраняют геометрию.
- [ ] Большой PDF прокручивается без блокировки toolbar и без обязательного ручного облегчённого режима.
- [ ] Последняя и самая дальняя страницы, масштаб и позиция прокрутки сохраняются атомарно и восстанавливаются после reload.
- [ ] Автосохранение показывает только «Сохранение…», спокойное успешное состояние либо «Не сохранено» с повтором без toast на каждую позицию.
- [ ] Baseline `reader-clean` и невидимый инвариант восстановления состояния проходят детерминированно.
