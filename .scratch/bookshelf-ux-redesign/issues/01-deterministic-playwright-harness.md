# 01 — Детерминированный Playwright-контур

**What to build:** Сделать текущий интерфейс Bookshelf воспроизводимо открываемым, наполняемым тестовыми данными и фотографируемым без Tauri, сети и реального Codex, чтобы последующая UX-переработка имела надёжную визуальную страховочную сетку.

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] Playwright запускает production-like frontend в одном закреплённом Chromium project с фиксированными viewport, locale, временем, идентификаторами и device scale factor.
- [ ] Browser test adapter реализует тот же предметный интерфейс команд, что и production adapter, записывает команды, моделирует loading/error и исключён из production bundle.
- [ ] Fixture builders детерминированно создают пустую и наполненную личную библиотеку и сбрасывают состояние перед каждым spec.
- [ ] Собственный PDF fixture содержит 8–12 страниц, текстовый слой, оглавление, изображение, схему, повторяемые поисковые фразы и абзац через границу страниц.
- [ ] Page objects содержат только доступные локаторы и пользовательские действия; данные создаются fixtures, assertions остаются в specs.
- [ ] Несколько снимков текущего интерфейса воспроизводимо проходят повторно и служат страховочной сеткой, а не целевым дизайном.
- [ ] CI при visual mismatch публикует expected, actual и diff и никогда не обновляет baseline автоматически.
