# 16 — Материал для передачи и экспорт Markdown

**What to build:** Читатель создаёт авторский материал для передачи из одной или нескольких идей, использует связанные эксперименты и экспортирует готовый результат в переносимый Markdown.

**Blocked by:** 11 — Назначения и история формулировок идеи; 14 — Практический эксперимент.

**Status:** resolved

- [ ] Материал поддерживает проблему, идею, пример применения, результат, ограничения и источник.
- [ ] Приложение подставляет ссылки на выбранные идеи и эксперименты, но не генерирует содержательный авторский текст.
- [ ] Готовый материал можно скопировать и сохранить как Markdown-файл.
- [ ] Изменение экспортированного файла не изменяет рабочее состояние Bookshelf.
