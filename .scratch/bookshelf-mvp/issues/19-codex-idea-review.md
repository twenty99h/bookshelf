# 19 — Проверка идеи через Codex App Server

**What to build:** По явному действию читателя Bookshelf запускает изолированный bundled Codex sidecar, проводит управляемый вход и потоково показывает одну проверку идеи. Отказ интеграции не повреждает данные и не блокирует основной цикл.

**Blocked by:** 18 — Пакет проверки и ручной fallback.

**Status:** ready-for-agent

- [ ] Codex запускается только для входа или явной проверки и получает ровно подтверждённый пакет.
- [ ] Поток ответа отображается рядом с идеей и может быть отменён читателем.
- [ ] Рабочая папка и состояние Codex отделены от личной библиотеки; Bookshelf не читает OAuth-токены.
- [ ] Отсутствие sidecar, отказ входа, несовместимый протокол и crash дают предметную ошибку и сохраняют доступ к ручному fallback.
