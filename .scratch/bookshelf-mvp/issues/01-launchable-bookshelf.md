# 01 — Запускаемая Bookshelf с устойчивым локальным состоянием

**What to build:** Bookshelf запускается как desktop-приложение, показывает пустую личную библиотеку и сохраняет локальное рабочее состояние между перезапусками. Этот первый тонкий вертикальный срез устанавливает предметную командную границу и основной desktop E2E seam для последующих тикетов.

**Blocked by:** None — can start immediately.

**Status:** resolved

- [ ] На чистом пользовательском состоянии приложение открывает пустую личную библиотеку без ошибки.
- [ ] Проверочное изменение локального состояния сохраняется после закрытия и повторного запуска.
- [ ] Frontend взаимодействует с рабочим состоянием только через предметную Rust-команду, а не через прямой SQL или общий файловый доступ.
- [ ] Автоматический desktop-тест проходит тот же наблюдаемый сценарий запуска и перезапуска.
