# 18 — Пакет проверки и ручной fallback

**What to build:** Читатель явно подготавливает, просматривает и копирует минимальный пакет проверки идеи для ручной передачи во внешний чат, не раскрывая полный PDF или не относящееся к проверке состояние.

**Blocked by:** 06 — Разбор черновой заметки.

**Status:** ready-for-agent

- [ ] Пакет содержит инструкцию, источник, выбранный фрагмент, авторскую формулировку, конкретный вопрос и критерии ответа.
- [ ] Перед копированием читатель видит точное содержимое пакета и подтверждает действие.
- [ ] Полный PDF, практические эксперименты и другие заметки автоматически не добавляются.
- [ ] Ручной fallback доступен без входа в Codex и не изменяет идею.
