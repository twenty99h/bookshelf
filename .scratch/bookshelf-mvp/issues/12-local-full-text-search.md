# 12 — Локальный полнотекстовый поиск

**What to build:** Читатель локально и без ИИ находит книги, идеи и источники по текстовому запросу. Результаты отражают актуальное авторское состояние после редактирования и удаления.

**Blocked by:** 06 — Разбор черновой заметки.

**Status:** resolved

- [x] Поиск находит совпадения в названиях книг, текущих формулировках идей и значимых полях источника.
- [x] Результат показывает предметный тип, контекст совпадения и позволяет открыть найденную запись.
- [x] Изменение или удаление сущности транзакционно обновляет индекс.
- [x] Поиск работает без сети и не отправляет запрос или содержимое во внешний процесс.

## Comments

FTS5 индексирует книги, авторские идеи и их источники, темы знаний и материалы для передачи. Пользовательский тест подтверждает открытие найденной записи с предметным типом и контекстом; индекс обновляется в одной SQLite-транзакции с рабочим состоянием.
