# 23 — Автоматические снимки рабочего состояния

**What to build:** Bookshelf автоматически хранит ограниченное число облегчённых снимков без PDF и может восстановить из снимка согласованное рабочее состояние после сбоя или прерванной записи.

**Blocked by:** 06 — Разбор черновой заметки.

**Status:** ready-for-agent

- [ ] Снимок содержит необходимое рабочее состояние, но не включает импортированные PDF.
- [ ] Создание нового снимка атомарно и не повреждает предыдущий пригодный снимок при обрыве.
- [ ] Приложение сохраняет только настроенное число последних снимков.
- [ ] Восстановление возвращает согласованные книги, черновые заметки и идеи и проходит проверку целостности.
