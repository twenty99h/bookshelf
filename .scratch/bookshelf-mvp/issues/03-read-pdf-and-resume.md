# 03 — Чтение PDF с оглавлением и восстановлением позиции

**What to build:** Читатель открывает импортированную книгу во встроенном локальном просмотрщике, переходит по встроенному оглавлению и после перезапуска продолжает с сохранённой страницы, масштаба и позиции.

**Blocked by:** 02 — Импорт текстового PDF в личную библиотеку.

**Status:** ready-for-agent

- [ ] PDF отображается без сетевой загрузки и без доступа WebView за пределы внутренней библиотеки.
- [ ] Встроенное оглавление позволяет перейти к соответствующему месту книги.
- [ ] Страница, масштаб и позиция прокрутки восстанавливаются после закрытия и повторного запуска.
- [ ] Сценарий проверен на PDF с колонками, листингами либо нетривиальными встроенными шрифтами.
