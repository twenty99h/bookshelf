# 05 — Черновая заметка из выделенного фрагмента

**What to build:** Во время чтения читатель выделяет фрагмент и быстро сохраняет черновую заметку с короткой мыслью или без неё. Черновик появляется в устойчивой очереди разбора, не заставляя прерывать либо завершать чтение.

**Blocked by:** 03 — Чтение PDF с оглавлением и восстановлением позиции.

**Status:** ready-for-agent

- [ ] Выделенный текст сохраняется как фрагмент книги с корректной страницей и непосредственным контекстом.
- [ ] Авторский комментарий необязателен.
- [ ] Черновая заметка остаётся в очереди разбора после завершения сеанса и перезапуска приложения.
- [ ] Сохранение черновика не переводит пользователя из просмотрщика принудительно.
