# 07 — Активное изучение и завершение чтения

**What to build:** Читатель выбирает одну книгу для активной фазы изучения и отдельно отмечает завершение работы с её текстом. Завершение чтения не закрывает изучение и не останавливает работу из других книг.

**Blocked by:** 02 — Импорт текстового PDF в личную библиотеку.

**Status:** resolved

- [ ] В каждый момент только одна книга находится в активной фазе изучения.
- [ ] Активация другой книги требует явного понятного перехода и сохраняет существующее состояние.
- [ ] Завершение чтения не завершает изучение автоматически.
- [ ] Незавершённая работа из неактивных книг остаётся доступной.
