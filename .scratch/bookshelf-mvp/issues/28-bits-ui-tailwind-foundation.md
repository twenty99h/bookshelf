# 28 — UI-фундамент на Bits UI и Tailwind CSS

**What to build:** Bookshelf использует Tailwind CSS 4 для визуальных токенов и оформления, а доступные интерактивные примитивы Bits UI скрыты за собственными компонентами `shared/ui`. Текущий экран личной библиотеки переносится на этот фундамент без изменения предметного поведения.

**Blocked by:** 01 — Запускаемая Bookshelf с устойчивым локальным состоянием.

**Status:** resolved

- [x] Tailwind CSS 4 подключён к SvelteKit-сборке без удалённых стилей, шрифтов или runtime-зависимостей.
- [x] Общие цвета, типографика, отступы, focus ring и состояния элементов выражены едиными токенами Tailwind.
- [x] Нужные примитивы Bits UI используются только через компоненты `src/shared/ui`, а feature-экраны не импортируют Bits UI напрямую.
- [x] Кнопка, поле ввода и стандартные состояния загрузки, ошибки и disabled текущего экрана перенесены в `shared/ui` с доступной клавиатурной навигацией и видимым фокусом.
- [x] Сценарий пустой библиотеки и сохранения локальной пометки визуально и функционально не регрессирует после миграции.
