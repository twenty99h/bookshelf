# 02 — Импорт текстового PDF в личную библиотеку

**What to build:** Самостоятельный читатель импортирует PDF во внутреннюю личную библиотеку и после перезапуска видит принадлежащую Bookshelf локальную копию. Неподдерживаемый PDF без пригодного текстового слоя получает понятное объяснение ограничения.

**Blocked by:** 01 — Запускаемая Bookshelf с устойчивым локальным состоянием.

**Status:** ready-for-agent

- [ ] Импорт текстового PDF создаёт книгу в личной библиотеке и копирует файл во внутреннее хранилище.
- [ ] Книга и её локальная копия остаются доступны после удаления или перемещения исходного файла.
- [ ] PDF без пригодного текстового слоя импортируется с явным предупреждением о недоступности выделения либо отклоняется с тем же объяснением.
- [ ] Ошибка или отмена импорта не оставляет частичную книгу либо бесхозную копию.
