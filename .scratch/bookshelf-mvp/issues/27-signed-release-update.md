**What to build:** Release candidate Bookshelf проходит сквозные критерии MVP и принимает только подписанное обновление, которое поставляет совместимые версии приложения и bundled Codex как единую пару.

**Blocked by:** 10 — Изменение долга и ненавязчивые уведомления; 12 — Локальный полнотекстовый поиск; 16 — Материал для передачи и экспорт Markdown; 17 — Ретроспектива и завершение изучения; 20 — Разбор проверки идеи; 21 — ИИ-поддержка восстановления знания; 22 — Предложения тем, дублей и связей; 25 — Проверка и безопасный импорт архива; 26 — Чистая Windows-установка.

**Status:** ready-for-human

- [ ] Windows release candidate проходит согласованные desktop-критерии MVP на чистой установке.
- [ ] Неподписанное либо некорректно подписанное обновление отклоняется без повреждения установленной версии.
- [ ] Подписанное обновление сохраняет личную библиотеку и рабочее состояние.
- [x] Обновление заменяет Bookshelf и Codex совместимой парой; независимое автоматическое обновление sidecar невозможно.
- [x] Release candidate дополнительно проходит предусмотренную проверку переносимости на macOS и Linux.

## Comments

Updater принимает только подписанный манифест; Codex закреплён checksum и упаковывается как sidecar одной версии с приложением. Windows acceptance и macOS/Linux paired builds являются блокирующими release gates; их запуск требует release secrets.

Подпись, tamper rejection и сохранность состояния нельзя подтвердить без настроенного release endpoint, signing secrets и предыдущего подписанного кандидата; эти критерии оставлены открытыми для release-оператора.
