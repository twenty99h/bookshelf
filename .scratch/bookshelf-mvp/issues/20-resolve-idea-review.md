# 20 — Разбор проверки идеи

**What to build:** После обратной связи ИИ читатель уточняет идею, оставляет её без изменений либо возвращает проверку на потом. Полный ответ остаётся временным и не превращается в постоянный источник истины.

**Blocked by:** 11 — Назначения и история формулировок идеи; 19 — Проверка идеи через Codex App Server.

**Status:** ready-for-agent

- [ ] До решения полный ответ доступен рядом с проверяемой идеей.
- [ ] Уточнение создаёт новую авторскую версию формулировки, не принимая текст ИИ автоматически.
- [ ] Решение «оставить без изменений» сохраняет текущую формулировку; «разобрать позже» оставляет видимое действие долга.
- [ ] После окончательного решения полный ответ удаляется, а факт проверки, решение и необязательный вывод читателя сохраняются.
