# 17 — Проверка атомарного снимка на большой библиотеке

**Spec:** [Предсказуемая архитектура Bookshelf](../spec.md)

**What to build:** Сопровождающий проекта получает воспроизводимые данные о корректности, размере и времени полного `LibraryState`, чтобы решение ADR-0006 можно было пересматривать по измерениям, а не предположениям.

**Blocked by:** 15 — Архив, снимки и настройки личной библиотеки.

**Status:** ready-for-agent

- [ ] Детерминированный большой синтетический снимок содержит репрезентативные книги, идеи, источники, темы знаний, связи, восстановления, сессии и материалы.
- [ ] Test проверяет полный serialize/persist/load/IPC-compatible round trip без потери или частичной замены данных.
- [ ] Проверка сообщает размер сериализованного снимка и измеренное время понятным воспроизводимым способом.
- [ ] Нестабильный жёсткий CI-порог миллисекунд не вводится.
- [ ] Результат не меняет решение ADR-0006 автоматически и не добавляет read models, partial patches или query cache.
- [ ] Проходят все frontend- и Rust-команды из `AGENTS.md`; generated bindings не имеют неожиданного diff.
